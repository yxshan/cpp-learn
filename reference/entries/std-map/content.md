# `std::map`

`std::map` 保存唯一键和关联值，并始终按比较器定义的顺序遍历。

## 快速信息

- 头文件：`<map>`
- 命名空间：`std`
- 标准：C++98 起
- 查找、插入、删除：对数复杂度

## 什么时候使用

需要有序键值数据、前驱后继操作或范围查询时使用。若排序没有价值，应衡量 `std::unordered_map` 的平均复杂度和哈希成本。

## 声明

```cpp
template<class Key, class T, class Compare = std::less<Key>,
         class Allocator = std::allocator<std::pair<const Key, T>>>
class map;
```

## 元素与返回值

元素类型是 `std::pair<const Key, T>`，键在容器内不可直接修改。插入接口通常返回迭代器以及是否实际插入的状态，具体形状取决于重载。

## 复杂度

查找、插入和删除通常为与元素数量对数相关的复杂度。按顺序完整遍历为线性复杂度。

## 生命周期与失效规则

插入不会使已有迭代器和引用失效；删除只使指向被删元素的迭代器和引用失效。

## 异常与约束

比较器必须形成严格弱序。键、值、比较器、分配器的构造或操作可能抛出异常；保证取决于具体成员函数。

## 与 JavaScript 的区别

JavaScript `Map` 保留插入顺序；`std::map` 按比较器排序。两者的键等价规则和复杂度模型也不同。

## 相关内容

`<map>` 给出关联容器概览，`std::string` 可作为常见键类型。
