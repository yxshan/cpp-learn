# 从路由核心到可运行的本地服务

这个 Milestone 不再把 stdin 当作 HTTP。进程绑定 `127.0.0.1:0`，服务线程接受真实连接，多个客户端线程并发发送 `/health` 请求；每次响应状态都写入 SQLite 指标表。

Judge 会先做 clean CMake/CTest，再以不同并发数和每客户端请求数执行集成输入。报告中的重复中位数是本机相对负载证据，不是跨机器 SLO。

你的 Portfolio 需要记录：复现命令、并发模型、总请求/错误/持久化计数、基线与扩展中位数、预期饱和点、停止条件，以及未知路由错误分类事故的告警、回滚和回归测试。

面试时从 HTTP 边界讲到 SQLite 指标、负载假设和失败止损；不要只说“做了一个路由函数”。
