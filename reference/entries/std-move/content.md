# `std::move`

`std::move` 不执行移动；它把表达式转换为右值引用，使接受右值的重载有机会转移资源。

## 快速信息

- 头文件：`<utility>`
- 命名空间：`std`
- 标准：C++11 起
- 运行时成本：仅类型转换

## 声明

```cpp
template<class T>
constexpr std::remove_reference_t<T>&& move(T&& value) noexcept;
```

## 参数

- `value`：将被视为可移动来源的表达式。调用者仍负责保证后续使用符合该类型对 moved-from 状态的约定。

## 返回值

返回引用到同一对象的右值引用。是否真的发生资源转移，取决于随后选择的构造函数、赋值运算符或函数重载。

## 复杂度与异常

转换本身是常数时间且不抛异常。实际移动操作的复杂度和异常保证由目标类型定义。

## 生命周期

`std::move` 不延长对象生命周期。移动后的标准库对象通常保持有效但状态未指定；可以销毁、重新赋值或调用明确允许的操作。

示例把字符串移动到新对象，并只使用目标对象的确定值。

## 常见错误

不要为了“优化”给每个表达式都加 `std::move`。对 `const` 对象使用它通常仍不能选择需要可修改来源的移动重载；在 `return` 局部变量时也可能妨碍复制消除。

## 与 JavaScript 的区别

JavaScript 的对象赋值复制引用；C++ 移动通常把资源控制状态从一个对象转移到另一个对象，同时保留两个可析构对象。

## 相关内容

`std::unique_ptr` 用移动表达独占所有权转移；`std::string` 展示常见的可移动值类型。
