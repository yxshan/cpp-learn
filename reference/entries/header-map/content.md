# `<map>`

`<map>` 声明按键排序的唯一键映射 `std::map` 和允许重复键的 `std::multimap`。

## 快速信息

- 标准：C++98 起
- 主要类型：`std::map`、`std::multimap`
- 顺序：由比较器建立严格弱序

## 什么时候使用

需要稳定的键顺序、对数复杂度查找或有序范围查询时使用。只关心平均常数时间查找且不需要顺序时，可评估无序关联容器。

## 键与比较器

键是否相同由比较器建立的等价关系决定，不一定由 `operator==` 决定。比较器必须持续满足严格弱序；运行中改变其依赖状态会破坏容器不变量。

## 生命周期与失效规则

插入通常不会使已有迭代器和引用失效。删除只使指向被删元素的迭代器和引用失效；对象销毁后全部失效。

## 常见错误

`operator[]` 在键不存在时会插入默认构造的值。只读查询时，优先根据意图选择 `find`、`contains` 或 `at`。
