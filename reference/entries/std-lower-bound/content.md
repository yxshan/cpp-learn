# `std::lower_bound`

`std::lower_bound` 在已按同一规则分区的半开范围中，返回第一个“不位于目标之前”的位置。
对普通升序数据，可把它理解为第一个不小于目标的元素，也就是合适的插入位置。

## 快速信息

- 头文件：`<algorithm>`
- 命名空间：`std`
- 标准：C++98 起；经典重载 C++20 起可用于常量求值
- 未找到：返回 `last`

## 什么时候使用

在已排序数组或 vector 中寻找阈值、重复值起点或保持顺序的插入位置时使用。数据无序且只
查询一次时，线性查找通常更直接；反复查询时应先排序或建立合适索引。

对 `std::map` 和 `std::set` 应优先使用同名成员函数。成员函数能利用树结构进行对数次节
点步进，而通用算法面对双向迭代器时可能做线性数量的递增。

## 代表性声明

```cpp
template<class ForwardIt, class T>
constexpr ForwardIt lower_bound(ForwardIt first, ForwardIt last,
                                const T& value);

template<class ForwardIt, class T, class Compare>
constexpr ForwardIt lower_bound(ForwardIt first, ForwardIt last,
                                const T& value, Compare comp);
```

C++20 另有 `ranges::lower_bound`。自定义比较器版本检查“元素是否位于 value 之前”，调用方
必须用同一规则建立输入分区。

## 分区前置条件

范围必须让所有满足 `element < value`（或 `comp(element, value)`）的元素都出现在不满足者
之前。完整升序足以满足条件，但不是必要条件。无序范围中偶然返回正确位置不能证明调用合
法；在本项目采用的 C++20 语义下，违反这项分区前置条件会导致未定义行为。

## 返回值

返回范围中第一个不满足 `element < value`（或 `comp(element, value)`）的位置。若所有元
素都位于目标之前，则返回 `last`，解引用前必须检查。对于重复值，它返回等价区间的起点，
而不是任意一个匹配位置。

即使目标值不存在，返回位置仍是保持当前分区关系的插入点；但算法只计算位置，不执行插
入，也不保证后续容器修改后该迭代器继续有效。

## 复杂度

比较次数最多为 `log2(N) + O(1)`。但接口只要求前向迭代器：非随机访问迭代器的递增次数
仍可能为线性。vector 等随机访问范围才同时具有对数比较和高效位置跳转；不要笼统写成对
任何容器“总时间 O(log N)”。

## 异常与生命周期

经典重载传播比较器与迭代器操作的异常，并且不修改范围。返回迭代器的寿命由原容器决定；
之后插入或删除可能按容器规则使它失效。

## 示例

“插入位置”在升序 vector 中找 25 的位置，并检查后输出索引和值；“延迟分桶”同时展示命
中阈值和 `end()` 溢出分支。

## 常见错误

- 对未按比较规则分区的数据调用。
- 未检查 `end()` 就解引用返回值。
- 以为返回任意相等元素，而不是等价区间起点。
- 对 set/map 使用通用算法并误以为迭代器步进也是对数。
- 排序使用一种比较器，查找又换用不一致规则。

## 与 JavaScript 的区别

JavaScript 标准数组没有直接的 lower_bound；常见做法是手写二分。C++ 算法把范围和比较器
显式传入，并可用于任何满足前向迭代器与分区前置条件的序列。

## 相关内容
