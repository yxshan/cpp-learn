# 哈希索引与状态不变量

你已经会使用 STL 容器；这一课把容器提升为“有行为契约的数据结构”。索引不只是能存数据，还必须在更新、删除和缺失查询后保持一致状态。

## 先预测

`emplace` 遇到已有键会发生什么？先预测第二次 `set alice ...` 后的查询结果，再运行公开样例验证。

## 任务

程序支持三条命令：`set key value`、`get key`、`erase key`。修复 set 语义，使同一键的新值覆盖旧值；保留显式 `find`，不要用查询操作意外插入缺失键。

## 工程解释

写出命令后的状态不变量，并区分平均 O(1)、摊销成本与最坏情况。完成代码不等于完成学习，Grade 前还要提交你的解释。
