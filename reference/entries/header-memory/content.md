# `<memory>`

`<memory>` 提供表达所有权、分配存储和在未初始化存储中构造对象的标准工具。

## 快速信息

- 标准：C++98 起，智能指针主体自 C++11 起
- 常用类型：`std::unique_ptr`、`std::shared_ptr`、`std::weak_ptr`
- 常用工厂：`std::make_unique`、`std::make_shared`

## 什么时候使用

优先用自动存储期对象和标准容器。确实需要动态生命周期、多态对象或可转移资源时，再选择能准确表达所有权的智能指针。

## 所有权模型

`unique_ptr` 表达唯一所有者，`shared_ptr` 通过共享控制块表达共同所有权，`weak_ptr` 观察共享对象但不延长其生命周期。它们不是可以随意互换的性能选项。

## 异常与自定义删除器

分配和对象构造可能抛出异常。智能指针的删除器属于其类型或控制状态的一部分，必须适配资源的正确释放方式。

## 示例

示例使用 `std::make_unique` 创建一个独占整数对象。

## 常见错误

不要用多个独立的 `shared_ptr` 直接接管同一个裸指针，也不要把裸观察指针误当所有者。创建智能指针时优先使用对应 `make_` 工厂。

## 相关内容

阅读 `std::unique_ptr` 和 `std::move` 理解独占所有权如何安全转移。
