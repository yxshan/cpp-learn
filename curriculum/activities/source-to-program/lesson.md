# 从源代码到可执行程序

你已经熟悉 JavaScript：把源文件交给浏览器或 Node.js，代码便能运行。C++ 多出一个需要建立直觉的阶段——源代码必须先经过编译和链接，形成适合当前操作系统与处理器的可执行程序。

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!\n";
    return 0;
}
```

在终端中可以这样完成第一次构建：

```bash
clang++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp -o hello
./hello
```

暂时不必记住所有参数。现在只需要区分三件事：`main.cpp` 是你编写的源代码；`clang++` 是编译器驱动；`hello` 是生成的可执行程序。

## 本课目标

- 能解释“编译”和“运行”不是同一个动作。
- 能识别 C++ 程序的入口 `main`。
- 遇到错误时，先判断它来自编译期还是运行期。

完成讲解后，请到练习区修改并运行第一个程序。本课不会因为“读完页面”自动计为掌握；后续独立练习才会产生能力证据。
