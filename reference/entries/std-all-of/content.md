# `std::all_of`

`std::all_of` 判断范围内是否每个元素都满足谓词。遇到反例时结果为 `false`；没有反例的
空范围按数学上的全称判断返回 `true`。

## 快速信息

- 头文件：`<algorithm>`
- 命名空间：`std`
- 标准：C++11 起；经典重载 C++20 起可用于常量求值
- 空范围：返回 `true`

## 什么时候使用

验证所有端口、配置或记录都满足一个不变量时使用。如果业务规定“至少要有一个元素且全部
有效”，应写成 `!range.empty() && all_of(...)`。需要知道首个失败位置时使用
`find_if_not`，避免先 all_of 再扫描一次。

## 代表性声明

```cpp
template<class InputIt, class UnaryPredicate>
constexpr bool all_of(InputIt first, InputIt last, UnaryPredicate pred);
```

C++17 的执行策略重载与 C++20 的 ranges 版本属于相邻接口，本页聚焦经典重载。

## 参数与前置条件

- `first`、`last`：组成有效的输入半开范围 `[first, last)`；二者必须来自同一范围边界。
- `pred`：对范围元素可调用的一元谓词。它应观察元素而不修改元素，也不能通过结构修改使
  当前迭代器范围失效。

谓词捕获的引用和指针必须在完整调用期间有效。执行策略重载还会提高迭代器类别、函数对象
复制和并发安全要求，不能直接套用经典重载的最小前提。

## 返回值与短路

若每个元素都使 `pred` 返回 `true`，结果为 `true`；遇到第一个反例即可返回 `false`。
因此不要依赖谓词执行固定次数，也不要用它承载必须完成的副作用。

空范围返回 true，因为不存在不满足条件的元素。这是标准语义，不代表“空配置已经通过业
务校验”；是否允许空集合应由调用方单独表达。

## 复杂度

设范围长度为 N，经典重载至多调用谓词 N 次。它可以在首个 `false` 处短路，最好情况可能
只调用一次；标准保证的是上界，而不是每次都遍历完整范围。算法本身只读取范围且不分配结
果容器。

## 异常、生命周期与并发

经典重载传播谓词和迭代器操作的异常。捕获的对象必须在算法执行期间存活。即使算法本身只
读范围，谓词读写共享外部状态时仍需要遵守线程同步规则。

## 示例

“全部为正”展示最小全称判断；“配置校验”组合服务名称和副本数两个条件，并得到一个明确
的失败结果。业务若不允许空服务列表，还应在调用处额外检查 `empty()`。

## 常见错误

- 认为空范围会返回 false。
- 在谓词里增加必须等于范围大小的计数，忽略短路。
- 校验失败后再次扫描寻找错误，而本来可以直接使用 `find_if_not`。
- 在谓词中修改被检查对象或容器。
- 把执行策略重载的错误处理规则套到经典重载。

## 与 JavaScript 的区别

JavaScript `Array.prototype.every` 的总体意图和空数组语义相近。C++ 版本作用于迭代器半开
范围，可处理多种容器，并要求调用者维护迭代器与捕获引用的有效性。
