# UDP、非阻塞 I/O 与事件循环

UDP 保留数据报边界，但不提供 TCP 的可靠有序字节流。一次 sendto 对应一个数据报；丢包、重复、乱序和载荷上限必须由协议设计处理。

非阻塞 socket 让线程不会卡在一次读操作上。事件循环先用 poll 等待 readiness，再调用 recvfrom 取走当前数据报；readable 只表示现在尝试不会阻塞，并不保证未来状态，也不替业务协议处理错误。

本实验只绑定 127.0.0.1 的动态端口，不依赖外网。请把 socket 所有权、关闭路径和每个事件周期的工作上限写清楚。

## 练习要求

在动态回环端口发送 UDP 数据报，用非阻塞 socket 与 poll 处理可读事件。

完成后回答反思题，并说明失败 mutation 破坏了哪个边界。
