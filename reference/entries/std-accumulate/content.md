# `std::accumulate`

`std::accumulate` 从一个显式初值开始，按输入顺序把范围元素折叠为单一结果。默认重载做加
法，自定义操作可构建总价、状态或字符串等其他累积结果。

## 快速信息

- 头文件：`<numeric>`
- 命名空间：`std`
- 标准：C++98 起；C++20 起可用于常量求值
- 顺序：确定的从左到右折叠

## 什么时候使用

求和、按顺序拼接或每一步都依赖前一累积状态时使用。若想把输入一一映射为输出范围，应使
用 `std::transform`；若数值操作允许重排并希望利用并行归约，可以评估 `std::reduce`，但
浮点和非结合操作的结果可能不同。

## 代表性声明

```cpp
template<class InputIt, class T>
constexpr T accumulate(InputIt first, InputIt last, T init);

template<class InputIt, class T, class BinaryOperation>
constexpr T accumulate(InputIt first, InputIt last, T init,
                       BinaryOperation op);
```

返回类型与中间累积器类型都是 `T`，由 `init` 决定，而不是由输入元素自动推导成“足够宽”
的类型。

## 返回值

返回按顺序处理完整个范围后的累积器。若 `[first, last)` 为空，不调用二元操作并直接返回
`init`。返回类型固定为 `T`；输入元素更宽、二元操作产生更宽的临时值，都不会自动改变最终
返回类型，因此调用者必须用合适类型的初值建立累积边界。

## 初值类型与折叠顺序

`std::accumulate(values.begin(), values.end(), 0)` 使用 int 累积器，即使 values 的元素是
`int64_t`。大型总和应传 `std::int64_t{0}` 等明确初值，避免在较窄中间类型中溢出或截断。

C++20 起每一步按顺序使用移动后的累积器调用操作，可支持只移动的中间状态。操作仍必须能
产生可赋回 T 的结果。

## 操作约束与复杂度

对范围中每个元素按顺序应用一次操作，总复杂度线性。操作不能修改输入元素，也不能使输入
迭代器或子范围失效。不要在折叠函数中向正在遍历的容器追加。

accumulate 的顺序保证适合非交换的操作，但调用者仍要保证数值计算不发生有符号溢出等未
定义行为。

## 异常与生命周期

二元操作、累积器赋值或迭代器操作抛出的异常会传播，没有部分结果返回。外部副作用可能已
发生，因此累积函数宜保持纯净。捕获引用的状态必须在整个调用期间存活。

## 示例

“整数求和”展示默认加法；“发票总价”用 `int64_t{0}` 固定累积器宽度，并通过自定义 lambda
把单价与数量折叠成总分值。

## 常见错误

- 用字面量 `0` 累加 64 位金额或字节数，导致中间类型过窄。
- 把 accumulate 当成可任意重排的并行 reduce。
- 在操作中修改输入范围或保存短命元素引用。
- 假设异常时能取得已经累积的部分结果。
- 对可能溢出的有符号整数求和而不定义边界策略。

## 与 JavaScript 的区别

JavaScript `Array.prototype.reduce` 的左折叠心智模型接近 accumulate；C++ 的初值静态类型
同时决定返回和中间累积器类型，并且输入以迭代器范围表示。
