# `<set>`

`<set>` 声明按值比较器排序的关联集合：唯一值的 `std::set` 与允许等价值重复的
`std::multiset`，以及相关非成员操作。

## 快速信息

- 头文件：`<set>`
- 命名空间：`std`
- 首次标准：C++98
- 核心选择：值是否唯一、是否需要排序和范围查询

## 什么时候包含

直接声明 set/multiset，或调用它们的 `std::erase_if`、比较与交换接口时，应显式包含
`<set>`。不能依赖 `<map>` 或某个聚合头文件偶然带入声明。

## 头文件中的主要实体

| 实体组 | 作用 | 版本提示 |
|---|---|---|
| `std::set<Key>` | 保存比较器意义下唯一的有序值 | C++98 |
| `std::multiset<Key>` | 保存可重复的有序值 | C++98 |
| `std::pmr::set`、`std::pmr::multiset` | 使用多态分配器的别名 | C++17 |
| 比较运算与 `std::swap` | 比较或交换完整集合 | 比较/交换自 C++98，三路比较自 C++20 |
| `std::erase_if` | 删除让谓词成立的元素 | C++20 |

当前 draft 中晚于 C++20 的范围接口不属于本页示例基线。

## 关键选择边界

set/multiset 的元素本身就是键，迭代器提供常量访问，不能原地改变排序依据。set 插入等价
键不会建立第二个元素；multiset 会保留它，并可用 `count` 或 `equal_range` 访问等价组。

若不需要排序、最小/最大值和区间查询，应比较 `<unordered_set>`。若每个键还要关联一个
值，转到 `<map>`。

## 头文件边界

`<set>` 不提供通用排序：容器自身持续维持顺序。对 set 调用 `std::sort` 既不适用其双向迭
代器，也没有必要。集合运算算法如 `set_union` 位于 `<algorithm>`，且输入范围需要有序。

## 常见错误

- 试图通过迭代器修改 set 元素。
- 把 set 当成插入顺序集合。
- 需要记录重复次数却选择唯一键 set。
- 依赖 `<map>` 传递包含 `<set>`。
- 认为 `<set>` 同时提供所有集合算法。
