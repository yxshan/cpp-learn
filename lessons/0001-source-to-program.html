02 · 读懂练习里的最少语法

int minutes{};
constexpr int session_minutes{25};

const int complete_sessions{minutes / session_minutes};
const int remaining_minutes{minutes % session_minutes};
  • int minutes{}：创建一个整数，并用 0 初始化。
  • constexpr：这个值在编译期就是常量，这里固定为 25。
  • const：初始化后不再修改。
  • /：两个整数相除时得到完整份数；% 得到余数。

先不用背这些关键词。你只要能根据名字和上下文说出四个变量分别代表什么。

为什么代码里到处有 std::？

std 是 C++ 标准库使用的命名空间。std::string、std::cout 和 std::cin 表示从标准库中取这些名字。今天不要用 using namespace std; 隐藏它，我们先把来源写清楚。

04 · 主动制造一次错误

检查通过后，把第一条输出最后的分号临时删除，再运行检查。观察错误中出现的：

  • 文件名
  • 行号和列号
  • error: 后面的描述
  • ^ 指向的位置

然后恢复分号并再次确认检查通过。你刚刚完成了第一次受控调试。

源码文本 / 可执行文件；是否成功生成并启动程序；指定输出文件名。表达不必相同，但含义应覆盖这些关键词。
