# `std::vector::push_back`

`push_back` 在容器末尾构造一个新元素，参数可以被复制或移动到该位置。

## 快速信息

- 头文件：`<vector>`
- 所属类型：`std::vector`
- 标准：C++98 起
- 复杂度：均摊常数

## 声明

```cpp
constexpr void push_back(const T& value);
constexpr void push_back(T&& value);
```

## 参数

左值参数被复制，右值参数通常被移动。若参数引用的是同一容器中的元素，应特别留意扩容与求值过程。

## 复杂度

单次调用可能因重新分配而移动全部元素，但一系列尾部追加的均摊复杂度为常数。

## 生命周期与失效规则

若新大小超过旧容量，所有迭代器、指针和引用都会失效；否则只有原来的尾后迭代器失效。

示例向空容器依次追加两个整数并输出结果。

## 常见错误

保存元素地址后继续追加可能留下悬空指针。需要提前降低重新分配概率时，可根据已知规模调用 `reserve`，但仍应遵守失效规则。
