# 函数与作用域

函数把名称、参数类型、返回类型与实现组织成一个可复用契约。局部变量只在其作用域内存在，调用者通过参数和返回值交换信息。

实现 `square`，读取一个整数并输出平方。

## 心智模型

先读函数声明，再分别检查输入、输出和副作用。值参数会得到一份独立的值；函数结束后局部变量被销毁，但返回值会交给调用者。这个边界比 JavaScript 的动态调用更早接受编译器检查。

## 检索练习

不运行程序，写出 `square(5)` 的参数、局部计算和返回值分别属于哪个作用域。再解释为什么在 `main` 中不能直接访问 `square` 的参数名。

常见误区：遗漏返回值、让函数偷偷依赖全局变量，或把声明与调用时的参数类型写成不同契约。
