# `std::array`

`std::array<T, N>` 保存恰好 `N` 个 `T`，把固定大小的连续元素序列包装成标准容器。

## 快速信息

- 头文件：`<array>`
- 命名空间：`std`
- 标准：C++11 起
- 存储：连续，大小不变

## 代表性声明

```cpp
namespace std {
template<class T, std::size_t N>
struct array;
}
```

`std::array<int, 3>` 和 `std::array<int, 4>` 是不同类型，因为 `N` 是模板参数。

## 复杂度

元素访问、迭代器算术和 `size()` 为常数复杂度。`fill()` 和逐元素 `swap()` 对
`N` 为线性复杂度。容器不分配可增长的动态存储，也不会发生扩容。

## 生命周期与失效规则

容器大小和存储位置不会因成员操作重新分配，指针、引用和迭代器在对应
`std::array` 对象的生命周期内仍关联该对象。交换两个数组会交换位置中的元素值，
已有迭代器不会改为指向另一个容器。

## 元素访问与异常

`at(n)` 在 `n >= size()` 时抛出 `std::out_of_range`。`operator[]` 要求索引有效；
`front()` 和 `back()` 要求容器非空。对于 `N == 0`，`begin() == end()`，且不能
访问元素。元素自身的构造、赋值、比较或交换异常会按相应操作传播。

## 初始化

优先使用花括号初始化。对于标量元素，`std::array<int, 3> values{};` 会清晰地进行
值初始化；不要误以为默认初始化总会把整数清零。

## 常见错误

需要增长时不要强行选择 `std::array`。也不要对 `std::array<T, 0>` 调用
`front()`、`back()` 或下标访问。

## 相关内容

`<array>` 声明该类型；`std::vector` 适合运行时大小的连续序列。
