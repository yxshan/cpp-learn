# `std::string`

`std::string` 是拥有、连续存储并可动态改变长度的窄字符序列。

## 快速信息

- 头文件：`<string>`
- 命名空间：`std`
- 标准：C++98 起
- 字符存储：连续

## 什么时候使用

需要保存、返回或修改一段文本时使用。仅需在调用期间观察文本时，不要为了方便无条件复制；可根据生命周期选择 `std::string_view` 或引用。

## 声明

```cpp
using string = basic_string<char>;
```

## 所有权与生命周期

对象拥有字符存储。`c_str()` 和 `data()` 返回的指针依赖字符串对象及其当前存储；对象销毁或某些修改操作后不能继续使用旧指针。

## 复杂度

按索引访问为常数复杂度。追加操作通常会涉及容量管理；插入、删除和搜索的复杂度取决于位置、长度与具体重载。

## 异常与错误

越界使用 `operator[]` 会导致未定义行为，而 `at()` 会检查边界并在越界时抛出 `std::out_of_range`。分配失败和元素操作异常按对应保证传播。

## 示例

示例使用 `+=` 追加文本，并输出最终字符串。

## 常见错误

不要把 `size()` 当作 Unicode 字符数量；对 UTF-8，它返回字节数量。也不要长期保存修改前取得的内部字符指针。

## 与 JavaScript 的区别

JavaScript 字符串不可变；`std::string` 可以修改，并显式参与复制、移动和资源管理。

## 相关内容

`<string>` 介绍类型族；`std::move` 解释如何允许资源所有权转移。
