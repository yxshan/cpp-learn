# `std::find`

`std::find` 从前向范围起点开始，返回第一个等于目标值的元素位置。

## 快速信息

- 头文件：`<algorithm>`
- 命名空间：`std`
- 标准：C++98 起
- 复杂度：至多线性比较

## 声明

```cpp
template<class InputIt, class T>
constexpr InputIt find(InputIt first, InputIt last, const T& value);
```

`constexpr` 适用于 C++20 起的该重载；更早标准中的返回与查找语义相同，但声明不带 `constexpr`。

## 参数

- `first`、`last`：有效的半开查找区间。
- `value`：与元素进行相等比较的目标值。

## 返回值

找到时返回第一个匹配元素的迭代器；没有找到时返回 `last`。返回值不拥有元素，其有效性依赖原范围。

## 复杂度

最多对区间中的每个元素进行一次与目标值的比较，因此是线性复杂度。

## 生命周期与约束

区间必须有效，比较表达式必须适用。调用后若容器操作使迭代器失效，先前的查找结果也不能继续使用。

## 示例

示例查找整数 `30` 并输出其从零开始的位置。

## 常见错误

解引用结果前必须检查它不等于结束迭代器。若容器自身提供更合适的查找成员，例如 `std::map::find`，应使用其数据结构优势。

## 相关内容

`<algorithm>` 解释通用算法区间，`std::vector` 是常见输入容器。

## 来源
