# 值、类型与输入输出

JavaScript 的变量可以在运行时装入不同类型；C++ 变量的类型在编译期确定。读取两个 `int`，计算结果，并观察类型如何同时约束存储、运算和接口。

把类型看作编译器提前检查的契约：它决定一段比特如何解释、允许哪些运算，也决定函数之间怎样交换数据。这里先只使用 `int`，避免把输入输出和数值转换混在一起。

## 任务

从标准输入读取两个整数，输出它们的和并换行。先预测 `10 + (-4)` 的结果，再运行验证。

## 检索练习

合上讲义回答：变量声明中的 `int` 在编译期提供了哪三类信息？如果输入不是整数，你希望程序怎样处理？本课先记录问题，后续再学习输入校验。

常见误区：忘记初始化变量、把输出提示文字混进判题结果，或依赖 JavaScript 式隐式类型转换。
