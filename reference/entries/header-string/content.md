# `<string>`

`<string>` 声明拥有字符序列的标准字符串类型及其常用非成员操作。

## 快速信息

- 标准：C++98 起
- 常用类型：`std::string`、`std::wstring`
- 相关能力：拼接、比较、搜索、数值转换

## 什么时候使用

程序需要拥有和修改文本时通常使用 `std::string`。只读借用已有字符数据时，可进一步了解 C++17 的 `std::string_view`，避免不必要的所有权和复制。

## 类型族

标准字符串是 `std::basic_string` 的别名族。字符类型、traits 和 allocator 是模板参数；`std::string` 使用 `char`。

## 生命周期与失效规则

字符串拥有其字符。可能重新分配存储的修改操作会使先前取得的指针、引用和迭代器失效；具体规则应按所调用的成员函数核对。

## 异常与编码

分配和字符操作可能抛出异常。`std::string` 存储字节序列，并不自动验证或转换 UTF-8；文本编码仍是应用层约定。

## 与 JavaScript 的区别

JavaScript 字符串不可变，而 `std::string` 可原地修改并拥有连续字符存储。两者的 `size` 也不等价于用户感知的字符数量。
