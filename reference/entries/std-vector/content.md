# `std::vector`

`std::vector` 是连续存储、可动态扩容的序列容器，通常是需要可增长数组时的首选。

## 快速信息

- 头文件：`<vector>`
- 命名空间：`std`
- 标准：C++98 起
- 元素存储：连续

## 什么时候使用

需要按索引访问、缓存友好的顺序遍历或与要求连续内存的接口交互时使用。频繁在序列中间插入时，应先评估移动元素的代价。

## 声明

```cpp
template<class T, class Allocator = std::allocator<T>>
class vector;
```

## 复杂度

按索引访问为常数复杂度；尾部追加通常为均摊常数复杂度；在中间插入或删除通常为线性复杂度。

## 生命周期与失效规则

扩容会使指向元素的迭代器、指针和引用全部失效。未扩容的操作仍需按具体成员函数规则判断失效范围。

## 与 JavaScript 的区别

它在用途上接近 JavaScript `Array`，但元素类型固定，存储连续，而且引用和迭代器可能因扩容失效。
