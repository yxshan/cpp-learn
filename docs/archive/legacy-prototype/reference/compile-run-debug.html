编译与运行速查

源码不是程序。先让编译器和链接器生成可执行文件，再由操作系统运行它。

main.cpp
源码 编译
检查并翻译 链接
组合成程序 运行
产生进程

本项目的基础命令

clang++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp -o app
./app
部分含义
clang++调用支持 C++ 的 Clang 驱动程序
-std=c++20使用 C++20 语言模式
-Wall -Wextra -Wpedantic开启一组有价值的警告
main.cpp输入的 C++ 源文件
-o app把生成的可执行文件命名为 app
./app运行当前目录中的 app

三类结果

  • 编译错误：没有生成新程序，先读第一条错误及其文件、行、列。
  • 警告：生成程序前发现可疑代码；学习阶段不要忽略。
  • 运行错误：已经生成程序，但执行时崩溃、卡住或产生错误结果。
