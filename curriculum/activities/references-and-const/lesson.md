# 引用与 const

C++ 引用是已有对象的别名，不是 JavaScript 对象引用。`const T&` 表达只读借用，`T&` 表达允许修改调用者对象。

实现 `swap_values(int&, int&)`。

## 心智模型

值参数复制，引用参数借用。看到 `T&` 时要问“谁拥有对象、函数能否修改它、借用会持续多久”；看到 `const T&` 时，接口明确承诺不会通过这个名字修改对象。

## 检索练习

先预测：交换函数若把两个参数都改成 `int`，调用后原变量会怎样？再用一句话区分“复制一个值”和“给已有对象起别名”。

常见误区：把引用当成可为空的指针，或因为 `const` 出现在参数里就误以为原对象永远不可变。
