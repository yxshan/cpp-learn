# std::optional

`std::optional<T>` 要么包含一个 `T`，要么处于未包含值的状态。它适合表达“缺失”
本身是正常结果、而不是错误或独立对象身份的接口。

## 头文件与声明

```cpp
#include <optional>
```

## 状态检查

使用 `has_value()` 或布尔转换检查是否包含值。`value()` 在无值时抛出
`std::bad_optional_access`；解引用空 optional 则不满足其前置条件。

## 生命周期

optional 直接管理所含对象的生命周期。`reset()` 会销毁当前值；`emplace()` 会
替换当前值并在 optional 内构造新对象。

## 何时使用

查找可能没有结果、解析允许“不提供该字段”时可以返回 optional。若需要携带失败
原因，应选择能表达错误信息的结果类型，而不是把所有失败压成“无值”。

## 常见陷阱

不要用 optional 代替每一个指针：对象身份、多态和共享所有权仍需要相应的句柄。
