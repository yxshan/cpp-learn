# `std::string`

`std::string` 是拥有、连续存储并可动态改变长度的窄字符序列。

## 快速信息

- 头文件：`<string>`
- 命名空间：`std`
- 标准：C++98 起
- 字符存储：连续

## 什么时候使用

需要保存、返回或修改一段文本时使用。仅需在调用期间观察文本时，不要为了方便无条件复制；可根据生命周期选择 `std::string_view` 或引用。

## 声明

```cpp
using string = basic_string<char>;
```

## 所有权与生命周期

对象拥有字符存储。`c_str()` 和 `data()` 返回的指针依赖字符串对象及其当前存储；对象销毁或某些修改操作后不能继续使用旧指针。

## 复杂度

按索引访问为常数复杂度。追加操作通常会涉及容量管理；插入、删除和搜索的复杂度取决于位置、长度与具体重载。

## 异常与错误

`operator[]` 要求 `pos <= size()`：当 `pos == size()` 时返回值为 `char{}` 的终止字符，
且不能把它修改成非零值；只有 `pos > size()` 才违反前置条件。`at()` 在
`pos >= size()` 时抛出 `std::out_of_range`，详见
[`[string.access]`](https://eel.is/c++draft/string.access)。分配失败和元素操作异常按
对应保证传播。

## 常见错误

不要把 `size()` 当作 Unicode 字符数量；它返回 `char` 元素数量，当字符串保存 UTF-8
编码单元时通常对应编码字节数，而不是 Unicode 标量值或用户感知字符数。也不要长期保存
修改前取得的内部字符指针。

## 与 JavaScript 的区别

JavaScript 字符串不可变；`std::string` 可以修改，并显式参与复制、移动和资源管理。

## 相关内容

`<string>` 介绍类型族；`std::move` 解释如何允许资源所有权转移。
