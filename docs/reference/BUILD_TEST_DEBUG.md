# Build, Test, and Debug Reference

1. Preprocessing and compilation validate each translation unit.
2. Linking resolves declarations to definitions across object files and libraries.
3. A Run supports experimentation but creates no mastery Evidence.
4. A Grade evaluates an immutable Source Snapshot through public, private, and applicable Sanitizer stages.
5. Reproduce the smallest failing input before changing code.
6. Read the first relevant compiler or Sanitizer diagnostic, not only the final cascade.

For multi-file work, keep declarations in headers, definitions in source files, and build/test target relationships explicit.
