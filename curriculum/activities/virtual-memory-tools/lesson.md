# 虚拟内存、mmap 与观测工具

进程看到的是虚拟地址空间。mmap 先建立地址范围与权限；物理页通常在首次访问时按需分配，因此虚拟大小、驻留集和实际触碰页数不是同一个指标。

本实验查询系统页大小，创建匿名私有映射并逐页写入，再释放映射。它在 macOS 与 Linux 上都使用 POSIX 接口；Linux 可结合 /proc、pmap、strace，macOS 可结合 vmmap 与 dtruss 观察映射和系统调用。

不要把申请成功理解为所有物理内存已经就绪，也不要用裸地址长期跨越映射生命周期。

## 练习要求

用 mmap 建立匿名映射并按页触碰，解释虚拟地址、页和驻留内存的区别。

完成后回答反思题，并说明失败 mutation 破坏了哪个边界。
