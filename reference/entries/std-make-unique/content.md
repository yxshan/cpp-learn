# std::make_unique

`std::make_unique<T>(args...)` 使用给定参数构造 `T`，并返回拥有该对象的
`std::unique_ptr<T>`。

## 头文件与声明

```cpp
#include <memory>
```

## 所有权

成功返回后，资源由结果智能指针独占。指针离开作用域或被重置时，对象自动销毁。
所有权可以移动，不能复制。

## 异常

分配失败或 `T` 的构造函数抛出异常时，函数不会返回半初始化的 unique_ptr；已由
语言和库机制建立的对象会按栈展开规则清理。

## 何时使用

创建普通独占对象时优先使用 `make_unique`。需要自定义删除器，或必须采用特殊
分配协议时，才直接构造相应的 `unique_ptr`。

## 常见陷阱

不要调用 `release()` 后忘记接管返回的裸指针；若只是结束所有权，应使用
`reset()` 或让智能指针自然离开作用域。
