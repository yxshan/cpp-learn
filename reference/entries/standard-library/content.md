# C++ 标准库

C++ 标准库提供容器、算法、字符串、内存管理、输入输出和并发等可移植设施。

## 快速信息

- 先按任务选择分类，再确认实体要求的头文件和最低标准版本。
- `std` 命名空间中的名字不是全局名字；示例默认显式写出 `std::`。
- “本地编译器支持”与“标准是否规定”是两件不同的事。

## 怎么查

已知名字时搜索完整符号，例如 `std::vector`。只知道需求时，可从“容器”或“算法”等分类开始。
