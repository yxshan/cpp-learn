# `std::count_if`

`std::count_if` 统计半开范围 `[first, last)` 中让一元谓词返回 `true` 的元素数量，不修改
范围。

## 快速信息

- 头文件：`<algorithm>`
- 命名空间：`std`
- 标准：C++98 起；经典重载 C++20 起可用于常量求值
- 返回类型：输入迭代器的 `difference_type`

## 什么时候使用

统计成功响应、超时请求或满足业务条件的记录总数时使用。如果只需要判断“至少有一个”，
`any_of` 或 `find_if` 更能表达意图并允许提前结束；如果需要得到匹配元素本身，应选择过滤
或复制算法。

## 代表性声明

```cpp
template<class InputIt, class UnaryPredicate>
constexpr typename iterator_traits<InputIt>::difference_type
count_if(InputIt first, InputIt last, UnaryPredicate pred);
```

C++17 还提供执行策略重载，C++20 提供 `ranges::count_if`。本页讨论经典迭代器接口。

## 谓词约束

谓词应能以输入元素调用，结果可转为 bool，并且不修改传入对象。不要在谓词中删除元素、
向容器追加或执行会使范围失效的操作。依赖副作用统计调用次数同样不合适；谓词应表达纯判
断。

## 返回值与复杂度

返回匹配数量，类型不保证是 `int` 或 `size_t`。需要与容器大小比较时要留意有符号性与转
换。经典 `count_if` 对 N 个元素恰好调用谓词 N 次，因此完整统计不会在第一次匹配后停止。

算法只需输入迭代器，可以处理单遍范围。总成本还包括每次谓词自身的成本。

## 异常与生命周期

经典重载会传播迭代器操作或谓词抛出的异常；中断时没有部分计数返回。捕获引用的谓词必须
保证引用对象存活，并避免与其他线程的冲突访问。

## 示例

“偶数计数”展示整数谓词；“慢请求计数”把阈值规则放入 lambda，并同时输出总样本数，让
统计含义清晰。

## 常见错误

- 只需要存在性，却完整扫描后再比较 `count > 0`。
- 假设返回类型固定为无符号 `size_t`。
- 在谓词中修改容器，令当前迭代器失效。
- 把“恰好 N 次谓词调用”误写成可能短路。
- 用带状态副作用的谓词驱动业务流程。

## 与 JavaScript 的区别

JavaScript 常用 `array.filter(predicate).length`，这会建立一个中间数组；`count_if` 直接统
计而不产生匹配集合。C++ 谓词还必须遵守迭代器和对象生命周期约束。

## 相关内容

全部满足阅读 `std::all_of`；查找某个具体元素阅读 `std::find`。
