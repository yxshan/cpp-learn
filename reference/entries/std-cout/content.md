# `std::cout`

`std::cout` 是与 C 标准流 `stdout` 关联的预定义窄字符输出流对象。

## 快速信息

- 头文件：`<iostream>`
- 命名空间：`std`
- 类型：`std::ostream`
- 标准：C++98 起

## 代表性声明

```cpp
namespace std {
extern ostream cout;
}
```

## 输出与状态

格式化输出会尝试把值转换为文本并交给关联的 stream buffer。生成输出失败会设置
`failbit`；输出期间出现异常会设置 `badbit`。默认情况下，失败通常通过流状态报告；
如果相应状态位被加入 `exceptions()` 掩码，操作可以抛出 `std::ios_base::failure`。

标准没有为通用 `cout` 写入规定统一的时间复杂度，因为实际成本取决于格式化、
缓冲、同步设置和外部设备。

## 换行与刷新

`'\n'` 写入换行字符，但不要求立即刷新缓冲区。`std::endl` 会先换行再调用
`flush()`；只有确实需要刷新时才应使用它，而不是把它当作普通换行写法。

## 生命周期

`std::cout` 在进入 `main` 前已经可用，并且不会在程序执行期间被销毁。成功执行
`operator<<` 不等于字节已经到达终端或文件，缓冲仍是输出模型的一部分。

示例依次写入文本、整数和换行符。

## 常见错误

输出表达式能够编译并不代表运行时输出一定成功。需要可靠处理写入失败时，应检查
流状态，或有意识地配置异常掩码。多线程写入时也不要假设整行不会与其他线程交错。

## 相关内容

`<iostream>` 声明该对象；`std::cin` 是对应的标准输入对象。
